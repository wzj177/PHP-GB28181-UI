# 前端报警模块对接文档

## 概述

报警模块包含两个主要功能：
1. **报警计划管理** - 配置报警联动规则（录像、快照）
2. **报警事件查询** - 查看设备上报的报警事件记录

---

## 一、报警计划管理

### 1.1 页面路由

| 路由 | 组件 | 说明 |
|------|------|------|
| `/alarm-plans` | `AlarmPlanList` | 报警计划列表 |

### 1.2 API 接口

#### 获取计划列表
```
GET /api/admin/alarm-plan
```

**响应示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "name": "移动侦测报警",
        "status": 1,
        "remark": "检测到移动时录像30秒",
        "snapshot_interval_sec": 0,
        "record_duration_sec": 30,
        "alarm_level": [1, 2],
        "alarm_method": [1, 2, 3],
        "alarm_type": null,
        "alarm_eventtype": null,
        "created_at": "2026-01-22 10:00:00",
        "updated_at": "2026-01-22 10:00:00"
      }
    ],
    "total": 1
  }
}
```

#### 创建/更新计划
```
POST /api/admin/alarm-plan       // 创建
PUT /api/admin/alarm-plan/{id}   // 更新
```

**请求参数：**
```json
{
  "name": "移动侦测报警",
  "status": 1,
  "remark": "检测到移动时录像30秒",
  "snapshot_interval_sec": 0,
  "record_duration_sec": 30,
  "alarm_level": [1, 2],
  "alarm_method": [1, 2, 3],
  "alarm_type": null,
  "alarm_eventtype": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 计划名称 |
| status | int | 否 | 状态 (1=启用, 0=禁用) |
| remark | string | 否 | 备注 |
| snapshot_interval_sec | int | 否 | 快照间隔(秒)，0=不抓拍 |
| record_duration_sec | int | 否 | 录像时长(秒)，0=不录像 |
| alarm_level | array | 否 | 报警级别匹配 [1,2,3,4] |
| alarm_method | array | 否 | 报警方式匹配 [1,2,3,4,5] |
| alarm_type | array | 否 | 报警类型匹配 |
| alarm_eventtype | array | 否 | 事件类型匹配 |

#### 删除计划
```
DELETE /api/admin/alarm-plan/{id}
```

#### 绑定通道
```
POST /api/admin/alarm-plan/{id}/channels
```

**请求参数：**
```json
{
  "device_id": "34020000001320456626",
  "channel_ids": ["34020000001310000001", "34020000001310000002"]
}
```

#### 解绑通道
```
DELETE /api/admin/alarm-plan/{id}/channels/{channelId}
```

## 二、报警事件查询

### 2.1 页面路由

| 路由 | 组件 | 说明 |
|------|------|------|
| `/alarm-events` | `AlarmEventList` | 报警事件列表 |

### 2.2 API 接口

#### 获取事件列表
```
GET /api/v2/alarm/events
```

**查询参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| device_id | string | 否 | 设备ID |
| channel_id | string | 否 | 通道ID |
| level | int | 否 | 报警级别 |
| method | int | 否 | 报警方式 |
| start | int | 否 | 起始位置 |
| limit | int | 否 | 每页数量 |

**响应示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "device_id": "34020000001320456626",
        "channel_id": "34020000001310000001",
        "level": 2,
        "method": 1,
        "type": null,
        "eventtype": 1,
        "description": "移动侦测报警",

        "latitude": 22.123456,
        "alarm_time": "2026-01-22 10:30:00",
```

```
GET /api/v2/alarm/events/{id}
```

#### 事件统计（需要后端实现）
```
GET /api/admin/alarm-event/stats
```

### 2.4 报警方式说明 (GB28181 国标)

| 方式 | 说明 |
|------|------|
| 1 | 电话报警 |
| 2 | 设备报警 |
| 3 | 短信报警 |
| 4 | GPS 报警 |
| 5 | 视频报警 |
| 6 | 设备故障报警 |
| 7 | 其他报警 |

### 2.5 报警类型说明 (GB28181 国标)

**重要**: 报警类型 `type` 的含义依赖 `method`，同一数字在不同 `AlarmMethod` 下含义不同。

#### method=2 (设备报警) 时的 type
| type | 说明 |
|------|------|
| 1 | 视频丢失报警 |
| 2 | 设备防拆报警 |
| 3 | 存储设备磁盘满报警 |
| 4 | 设备高温报警 |
| 5 | 设备低温报警 |

#### method=5 (视频报警) 时的 type
| type | 说明 |
|------|------|
| 1 | 人工视频报警 |
| 2 | 运动目标检测报警 |
| 3 | 遗留物检测报警 |
| 4 | 物体移除检测报警 |
| 5 | 绊线检测报警 |
| 6 | 入侵检测报警 |
| 7 | 逆行检测报警 |
| 8 | 徘徊检测报警 |
| 9 | 流量统计报警 |
| 10 | 密度检测报警 |
| 11 | 视频异常检测报警 |
| 12 | 快速移动报警 |
| 13 | 图像遮挡报警 |

#### method=6 (设备故障报警) 时的 type
| type | 说明 |
|------|------|
| 1 | 存储设备磁盘故障报警 |
| 2 | 存储设备风扇故障报警 |

### 2.6 事件类型说明 (EventType)

**注意**: 事件类型 `eventtype` **仅在 method=5 且 type=6 (入侵检测) 时才有意义**。

| eventtype | 说明 |
|----------|------|
| 1 | 进入区域 |
| 2 | 离开区域 |

```vue
  device_id: '',
  channel_id: '',

const list = ref([]);

  pageSize: 20,
  total: 0,

  week: 0,
  month: 0,

    params: {
      ...filters,
      start: (pagination.page - 1) * pagination.pageSize,
      limit: pagination.pageSize,
      alarm_time_gte: dateRange.value[0],
      alarm_time_lte: dateRange.value[1],
    },
  });
  list.value = data.data.list;
  pagination.total = data.data.total;
};

const getLevelType = (level: number) => {
  const map = { 1: 'info', 2: 'warning', 3: 'danger', 4: 'danger' };
  return map[level] || 'info';
};

const getMethodText = (method: number) => {

    2: '设备报警',
    3: '短信报警',
    4: 'GPS报警',
    5: '视频报警',
    6: '设备故障报警',
    7: '其他报警'
  };
  return map[method] || '-';
};
</script>
```

## 三、实时报警通知（可选）

如需实时接收报警通知，可通过 WebSocket 或 SSE 实现：

### WebSocket 方式
```javascript
const ws = new WebSocket('ws://your-domain/ws/alarm');
ws.onmessage = (event) => {
  const alarm = JSON.parse(event.data);
  // 显示报警通知
  showNotification(alarm);
};
```

### SSE 方式
```javascript
const es = new EventSource('/api/v2/alarm/events/stream');
es.onmessage = (event) => {
  const alarm = JSON.parse(event.data);
  // 显示报警通知
  showNotification(alarm);
};
```

## 四、状态管理建议

```typescript
// store/alarm.ts
export const useAlarmStore = defineStore('alarm', () => {
  const plans = ref<AlarmPlan[]>([]);
  const events = ref<AlarmEvent[]>([]);
  const stats = ref<AlarmStats>({
    today: 0,
    week: 0,
    month: 0,
    total: 0,
  });

  const loadPlans = async () => {
    const { data } = await axios.get('/api/admin/alarm-plan');
    plans.value = data.data.list;
  };

  const loadEvents = async (filters: any) => {
    const { data } = await axios.get('/api/v2/alarm/events', { params: filters });
    events.value = data.data.list;
    return data.data;
  };

  const loadStats = async () => {
    const { data } = await axios.get('/api/admin/alarm-event/stats');
    stats.value = data.data;
  };

  return {
    plans,
    events,
    stats,
    loadPlans,
    loadEvents,
    loadStats,
  };
});
```

## 五、权限说明

确保用户角色具有以下权限标识：
- `alarm-plan.list` - 查看报警计划
- `alarm-plan.create` - 创建报警计划
- `alarm-plan.update` - 更新报警计划
- `alarm-plan.delete` - 删除报警计划
- `alarm-event.list` - 查看报警事件
