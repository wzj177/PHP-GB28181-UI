# GB28181 设备控制 API 文档

## 概述

本文档描述了 GBVR-IoT 管理后台 GB28181 设备控制相关的 API 接口，供前端开发人员对接使用。

**API 基础路径**: `/api/admin/gb28181`

**认证方式**: 所有接口需要在请求头中携带认证 Token
```
Authorization: Bearer {token}
```

**统一响应格式**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {}
}
```

**公共参数说明**:
| 参数 | 类型 | 说明 |
|------|------|------|
| device_id | string | 设备国标 ID（20 位） |
| channel_id | string | 通道国标 ID（20 位） |

| `scan_set_speed` | 设置自动扫描速度 |

**响应示例**:
```json
{
```

## 3. 设备查询

### 3.1 从设备查询预置位

**接口**: `POST /api/admin/gb28181/presets/query-from-device`

**说明**: 向设备发送 PresetQuery 查询命令。设备将异步返回预置位列表，结果通过 Gateway Hook 推送到 API 层并同步到数据库。查询完成后通过 `GET /api/admin/gb28181/presets` 获取最新列表。

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| device_id | string | 是 | 设备国标 ID |
| channel_id | string | 是 | 通道国标 ID |

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "message": "预置位查询命令已发送，设备将异步返回结果"
  }
}
```

---

### 3.2 设备配置查询

**接口**: `POST /api/admin/gb28181/device-control/config-query`

**说明**: 向设备发送 ConfigDownload 查询命令。设备将异步返回配置信息（设备名称、心跳参数等），结果通过 Gateway Hook 推送到 API 层并更新到设备记录。

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| device_id | string | 是 | 设备国标 ID |
| channel_id | string | 是 | 通道国标 ID |
| config_type | string | 否 | 配置类型，默认 `BasicParam` |

**config_type 取值**:
| 值 | 说明 |
|-----|------|
| `BasicParam` | 基本参数（默认） |
| `VideoParamOpt` | 视频参数（可选） |
| `SVACEncodeConfig` | SVAC 编码配置（可选） |
| `SVACDecodeConfig` | SVAC 解码配置（可选） |

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "message": "配置查询命令(BasicParam)已发送"
  }
}
```
