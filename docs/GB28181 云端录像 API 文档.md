# GB28181 云端录像 API 文档

> Base URL: `/api/admin/gb28181`
> 认证：需要 Admin Token（`AuthIdentityMiddleware` + `PermissionCheckMiddleware`）

---

## 一、录像计划管理

### 1.1 获取录像计划列表

```
GET /record-plans
```

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 否 | 模糊搜索计划名称 |
| status | int | 否 | 状态筛选（0=禁用，1=启用） |
| start | int | 否 | 分页偏移，默认 0 |
| limit | int | 否 | 每页条数，默认 20 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "name": "7x24小时录像",
        "status": 1,
        "remark": "全天候录像",
        "limit_space": 10737418240,
        "limit_days": 30,
        "over_step_plan": "del_file",
        "partner_id": 0,
        "created_at": "2026-02-27 10:00:00",
        "updated_at": "2026-02-27 10:00:00",
        "channel_count": 5
      }
    ],
    "paginator": { "total": 1, "offset": 0, "limit": 20 }
  }
}
```

### 1.3 创建录像计划

```
POST /record-plans
```

**Body 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 计划名称（唯一） |
| remark | string | 否 | 备注 |
| status | int | 否 | 是否启用（0/1），默认 0 |
| limit_space | int | 否 | 录制空间限制（Byte），0=不限 |
| limit_days | int | 否 | 录制天数限制，0=不限 |
| over_step_plan | string | 否 | 超限策略：`stop_record`(停止录像) / `del_file`(删除旧文件，默认) |
| ranges | array | 否 | 时间段数组，可在创建时一并设置 |

**ranges 数组元素：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| week_day | string | 是 | 星期：MON/TUE/WED/THU/FRI/SAT/SUN |
| start_time | string | 是 | 开始时间（HH:MM 格式） |
| end_time | string | 是 | 结束时间（HH:MM 格式） |

**请求示例：**

```json
{
  "name": "工作日白天录像",
  "status": 1,
  "limit_days": 30,
  "over_step_plan": "del_file",
  "ranges": [
    { "week_day": "MON", "start_time": "08:00", "end_time": "18:00" },
    { "week_day": "TUE", "start_time": "08:00", "end_time": "18:00" },
    { "week_day": "WED", "start_time": "08:00", "end_time": "18:00" },
    { "week_day": "THU", "start_time": "08:00", "end_time": "18:00" },
    { "week_day": "FRI", "start_time": "08:00", "end_time": "18:00" }
  ]
}
```

### 1.4 更新录像计划

```
PUT /record-plans/{id}
```

**Body 参数：** 同创建，所有字段均为可选。传入 `ranges` 会全量替换时间段。

### 1.5 删除录像计划

```
DELETE /record-plans/{id}
```

> 删除时会自动解绑所有关联通道（将通道的 `record_plan_id` 置 0），并删除所有时间段。

### 1.6 启用/禁用录像计划

```
POST /record-plans/{id}/toggle
```

**Body 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | int | 是 | 0=禁用，1=启用 |

### 1.7 设置时间段（全量替换）

```
POST /record-plans/{id}/ranges
```

**Body 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ranges | array | 是 | 时间段数组（格式同创建），会删除旧数据后全量写入 |

### 1.8 绑定通道到录像计划

```
POST /record-plans/{id}/channels
```

**Body 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| channel_ids | int[] | 是 | 通道主键 ID 数组 |

**响应：**

```json
{ "code": 0, "data": { "count": 3 }, "message": "已绑定 3 个通道" }
```

### 1.9 获取录像计划绑定的通道

```
GET /record-plans/{id}/channels
```

### 1.10 解绑通道

```
DELETE /record-plans/channels/{channelId}
```

> `channelId` 为通道表主键 ID（非 GB28181 通道编号）。

## 二、录像任务管理

### 2.1 获取录像任务列表

```
GET /record-tasks
```

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| task_type | string | 否 | 任务类型：plan / alarm / playback_download |
| device_id | string | 否 | 设备国标 ID |
| channel_id | string | 否 | 通道国标 ID |
| status | string | 否 | 任务状态（见下方枚举） |
| media_server_id | string | 否 | 媒体服务器 ID |
| start_time_gte | int | 否 | 开始时间 >= (时间戳) |
| start_time_lte | int | 否 | 开始时间 <= (时间戳) |
| end_time_gte | int | 否 | 结束时间 >= (时间戳) |
| end_time_lte | int | 否 | 结束时间 <= (时间戳) |
| order_by | string | 否 | 排序字段，默认 created_at |
| order_direction | string | 否 | 排序方向 ASC/DESC，默认 DESC |
| start | int | 否 | 分页偏移 |
| limit | int | 否 | 每页条数 |

**任务状态枚举：**

| 值 | 说明 |
|----|------|
| pending | 待执行 |
| inviting | INVITE 中 |
| wait_stream | 等待流 |
| recording | 录像中 |
| finalizing | 完成中 |
| done | 已完成 |
| failed | 失败 |
| cancelled | 已取消 |

**响应：** 分页列表，done 状态的任务会附带 `record_file` 字段。

### 2.2 删除/取消录像任务

```
DELETE /record-tasks/{id}
```

> 进行中的任务（pending/inviting/wait_stream/recording/finalizing）会先取消再删除；已完成/失败/已取消的任务直接删除。

## 四、通道录像配置字段

通过通道更新接口设置录像计划绑定：

```
PUT /channels/{id}
```

**可设置的录像相关字段：**

| 参数 | 类型 | 说明 |
|------|------|------|
| record_plan_id | int | 通过录像计划绑定接口设置，不直接更新 |
| record_status | int | 由后台进程自动维护（0=未录像，1=录像中） |
| close_live | int | 0=正常，1=关闭直播 |
| auto_live | int | 0=手动，1=自动直播 |

## 五、统一响应格式

**成功响应：**

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

**错误响应：**

```json
{
  "code": -1,
  "message": "错误描述"
}
```

**分页结构（paginator）：**

```json
{
  "total": 100,
  "offset": 0,
  "limit": 20,
  "currentPage": 1,
  "lastPage": 5
}
```
